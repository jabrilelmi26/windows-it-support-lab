# Help Desk Troubleshooting Runbook — Practice Example

1. Verify requester identity using the organization's **approved** process. Never request a password.
2. Record affected device, application, error text, start time, and business impact.
3. Confirm scope: one user, one device, one room, or many users.
4. Check basic conditions: power, cable/Wi-Fi, login method, network connectivity, recent changes.
5. Reproduce the issue only with permission; take sanitized notes.
6. Select a safe corrective action within your permissions; escalate access or security issues.
7. Verify the issue is resolved with the user; document test result and resolution.
8. Close the ticket or escalate, including the next owner and user communication.

## Prioritization exercise
`impact` and `urgency` are each scored 1–3 (3 = highest). Ticket score = impact × urgency. This example is not an industry standard SLA.

## Sample ticket note
Ticket HD-103: Multiple lab devices cannot reach the network. Record symptoms, verify one known-good device, document interface and switch observations, then escalate shared-infrastructure issues to network staff. Do **not** change production network settings without approval.
